# java-kanban

Учебный проект. Бэкенд для трекера задач (аналог канбан-доски).

## Что умеет

- Создавать, обновлять, удалять задачи, эпики и подзадачи
- Управлять статусами (NEW, IN_PROGRESS, DONE)
- Показывать историю просмотров
- Сохранять состояние на сервере через HTTP-запросы

## Технологии

- Java Core
- HTTP (KVServer / KVClient)
- Gson (JSON)
- JUnit (тесты)
